# Source launchers / 源码启动入口

这些入口仅用于源码运行和故障排查。普通用户请从[发布页](https://github.com/kaitongg-bit/DIYcodex-bubble/releases/latest)下载 macOS DMG 或 Windows EXE 安装包。

- macOS：`Start Bubble Studio.command` 打开工坊；`Start Bubble Apps.command` 恢复已选气泡。
- Windows：`Start Bubble Studio.cmd` 打开工坊；`Start Bubble Apps.cmd` 恢复已选气泡。
- `Open Bubble Studio` / `Open Bubble Apps` 是静默打开入口；`START HERE` 是旧版定位入口。

请保留仓库目录结构；不要单独移动这些文件。运行环境与源码说明见 [DEVELOPMENT.md](../../DEVELOPMENT.md)。

These launchers are for source checkouts and troubleshooting. End users should download the DMG or EXE installer. Keep the repository directory structure intact; do not move launchers individually. See [development notes](../../DEVELOPMENT.en.md) for runtime requirements.
